Paper Empires · Métricas

Política de privacidad · última actualización: 30 de septiembre de 2026

«Paper Empires Métricas» es una herramienta interna del canal de YouTube Paper Empires (@thepaperempires_co). La usa únicamente su propietario para leer las estadísticas de su propio canal. No es un servicio para terceros.

Qué datos lee

  • Estadísticas del propio canal a través de la YouTube Data API y la YouTube Analytics API (vistas, tiempo de visualización, retención, suscriptores, impresiones), con permisos de solo lectura (youtube.readonly y yt-analytics.readonly).
  • No lee datos de otras personas ni de otros canales. No publica, borra ni modifica nada.

Dónde se guardan

Los datos se guardan solo en el computador del propietario, en archivos locales. No se envían a servidores de terceros, no se venden, no se comparten y no se usan para publicidad.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Al retirarlo, la herramienta deja de poder leer estadísticas.

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Privacy policy (English)

"Paper Empires Métricas" is an internal tool used only by the owner of the YouTube channel Paper Empires to read that channel's own statistics, with read-only scopes. Data is stored only on the owner's computer; it is never sold, shared or used for advertising. Access can be revoked at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
