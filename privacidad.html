Paper Empires Publisher · Privacy Policy

Last updated: October 5, 2026

«Paper Empires Publisher» (formerly «Paper Empires Métricas») is an internal tool of the YouTube channel Paper Empires (@thepaperempires_co). It is used only by the owner of the channel to publish and schedule the channel's own videos on its own accounts (YouTube, TikTok, Facebook and Instagram) and to read the statistics of those accounts. It is not offered to third parties and has no other users.

YouTube API Services

This tool uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to the data that Google processes.

  • What it does: uploads the channel's own videos, sets their title, description, tags, privacy status, scheduled publication time, custom thumbnail and caption tracks, and reads the channel's own statistics (views, watch time, retention, subscribers, impressions) through the YouTube Data API and the YouTube Analytics API.
  • What it does not do: it does not access other users' channels, comments or private data, does not sell, share or transfer any data, and does not show advertising.

TikTok

The tool uses TikTok Login Kit and the Content Posting API to publish the channel's own short videos on the owner's TikTok account. It reads only the basic profile of that account (open ID, display name, avatar) and the creator information required to post (allowed privacy levels, maximum duration). Before each post the owner reviews the video, chooses the privacy level and the interaction settings, and gives explicit consent. The TikTok Terms of Service and TikTok Privacy Policy apply.

Meta (Facebook and Instagram)

The tool uses the Facebook Graph API and the Instagram API to schedule the channel's own reels on its own Facebook page and Instagram account, and to read their statistics.

Where the data is stored

Access tokens and statistics are stored only on the owner's computer, in local files that are not published. No data is stored on external servers by this tool. Statistics are kept while they are useful for the channel's own analysis and can be deleted at any time.

How to revoke access and delete data

  • Google / YouTube: Google security settings → third-party access.
  • TikTok: TikTok app → Settings and privacy → Security → Manage app permissions.
  • Meta: Facebook → Settings → Apps and websites.
  • To request the deletion of any stored data, write to the contact address below: it is deleted within 7 days.

Paper Empires Publisher · Política de privacidad

Última actualización: 5 de octubre de 2026

«Paper Empires Publisher» (antes «Paper Empires Métricas») es una herramienta interna del canal de YouTube Paper Empires (@thepaperempires_co). La usa únicamente su propietario para publicar y programar sus propios vídeos en sus propias cuentas (YouTube, TikTok, Facebook e Instagram) y para leer las estadísticas de esas cuentas. No se ofrece a terceros y no tiene otros usuarios.

Servicios de la API de YouTube

Esta herramienta usa los servicios de la API de YouTube. Al usarla aceptas las Condiciones de servicio de YouTube. A los datos que trata Google se les aplica la Política de privacidad de Google.

  • Qué hace: sube los vídeos del propio canal, pone su título, descripción, etiquetas, estado de privacidad, hora de publicación programada, miniatura y subtítulos, y lee las estadísticas del propio canal (vistas, tiempo de visualización, retención, suscriptores, impresiones) con la YouTube Data API y la YouTube Analytics API.
  • Qué no hace: no accede a canales, comentarios ni datos privados de otros usuarios, no vende, comparte ni transfiere datos y no muestra publicidad.

TikTok

La herramienta usa TikTok Login Kit y la Content Posting API para publicar los vídeos cortos del propio canal en la cuenta de TikTok del propietario. Solo lee el perfil básico de esa cuenta (identificador, nombre, avatar) y la información de creador necesaria para publicar (niveles de privacidad permitidos, duración máxima). Antes de cada publicación el propietario revisa el vídeo, elige la privacidad y las opciones de interacción y da su consentimiento expreso. Se aplican las Condiciones de servicio y la Política de privacidad de TikTok.

Meta (Facebook e Instagram)

La herramienta usa la Graph API de Facebook y la API de Instagram para programar los reels del propio canal en su propia página de Facebook y su cuenta de Instagram, y para leer sus estadísticas.

Dónde se guardan los datos

Los tokens de acceso y las estadísticas se guardan solo en el ordenador del propietario, en archivos locales que no se publican. La herramienta no guarda datos en servidores externos. Las estadísticas se conservan mientras sirven para el análisis del propio canal y se pueden borrar en cualquier momento.

Cómo revocar el acceso y borrar los datos

  • Google / YouTube: ajustes de seguridad de Google → acceso de terceros.
  • TikTok: app de TikTok → Ajustes y privacidad → Seguridad → Gestionar permisos de apps.
  • Meta: Facebook → Configuración → Apps y sitios web.
  • Para pedir el borrado de cualquier dato guardado, escribe a la dirección de contacto: se borra en 7 días.
